# 📊 Sales Dashboard - Power BI

This repository contains my **Sales Dashboard** project built with **Power BI Desktop**.  
The dashboard provides insights into sales performance, revenue trends, and customer behavior to support data-driven decision making.  

---

## 🚀 Project Overview
- Designed an **interactive sales dashboard** using Power BI.  
- Connected to sales dataset (e.g., Excel/CSV/SQL).  
- Performed data cleaning and transformation in **Power Query**.  
- Created **DAX measures** for KPIs like Revenue, Profit, Discount, and Average Order Value.  
- Built dynamic visuals with filters and slicers for interactive analysis.  

---

## 📂 Repository Contents
- `Sales_Dashboard.pbix` → Main Power BI file.  
- `data/` → (Optional) Contains the dataset used (CSV/Excel format if shareable).  
- `screenshots/` → Dashboard screenshots for quick preview.  
- `README.md` → Documentation of the project.

## 📊 Key Insights
- Total Sales, Profit, and Discount KPIs.  
- Monthly/Yearly Sales Trends.  
- Top-selling Products & Categories.  
- Regional/Market-wise performance.  
- Customer segmentation based on revenue contribution.
